#### what is this game?

- a simple game about remembering the old layout of a graveyard, then you have to recreate it!
- you only have 10 seconds to remember everything inside the graveyard walls!

#### how can i play this?

- you can find the demo on my [itch.io](https://derukaeru.itch.io/gravegrapher)!

#### what i used to make this game

- the game engine i used is godot, and thats basically it

- plus aseprite for some of the art
